# Data and materials for: Human Dependence on Large Language Models: A Systematic Review and Taxonomy of Cognitive, Behavioral, Decision-Making, and Emotional Impacts

**Authors:** anonymized for double-anonymized peer review
**Licence:** CC BY 4.0
**Reporting standard:** PRISMA 2020
**Final search:** 30 September 2026
**Registration:** not prospectively registered

## Contents

| Folder / file | Description |
|---|---|
| `01_search/search_strings.txt` | Full search strings for Web of Science, Scopus, PubMed, ACM Digital Library and IEEE Xplore |
| `01_search/search_audit_trail.csv` | Date run, record count, date limits and field restrictions for each source |
| `02_screening/prisma_flow_counts.csv` | Stage-by-stage counts behind the PRISMA 2020 flow diagram |
| `02_screening/exclusion_codes.csv` | Definitions of exclusion codes E1–E6 |
| `03_extraction/extraction_sheet.xlsx` | Included studies (n = 91), MMAT consensus ratings, summary counts and codebook |
| `03_extraction/included_studies.csv` | Same study data in open CSV format |
| `03_extraction/codebook.csv` | Definition of every variable and category |
| `04_quality/mmat_consensus_ratings.csv` | Consensus MMAT 2018 ratings (C1–C5) for each study |
| `04_quality/mmat_independent_ratings.xlsx` | Each reviewer's independent ratings (R1, R2) before consensus, with item-level agreement, raw agreement and Cohen's kappa |
| `04_quality/mmat_independent_and_consensus_ratings.csv` | Full appraisal record: MMAT category, S1–S2, R1 and R2 ratings, consensus ratings, criteria met and appraisal notes for each study |
| `05_reporting/PRISMA_checklist.pdf` | Completed PRISMA 2020 and PRISMA 2020 for Abstracts checklists |

## Notes

- Study findings are recorded as stated in each study's published abstract or record. They are not harmonised effect sizes.
- Full texts and database-exported abstracts are not shared because of copyright and licence restrictions. Bibliographic identifiers (titles, authors, years, DOIs) are provided instead.
- CSV files are UTF-8 encoded.
- The record-level screening log is available from the corresponding authors on reasonable request.
